- Les layers lambda sont compilées localement pour créer les zip à télécharger
Créer deux Lambda Layers séparées pour :
    * lightfm compilé sans OpenMP
    * numpy et dépendances mathématiques (scipy, etc.)
# 1. Préparer l’environnement (dans un dossier avec un sous-dossier python)
docker run -it --rm -v "$PWD":/lambda-build public.ecr.aws/lambda/python:3.11 bash
# 2. Installer LightFM sans OpenMP
cd /lambda-build
pip install Cython
pip install lightfm --no-binary :all: --no-use-pep517 -t python/
# 3. Zippoer le dossier python et importer dans lambda
# 4. Mêmes étapes pour numpy
docker run -it --rm -v "$PWD":/lambda-build public.ecr.aws/lambda/python:3.11 bash
cd /lambda-build
pip install numpy scipy scikit-learn --platform manylinux2014_x86_64 --only-binary=:all: --target python/
# 5. ZIP et chargement de la seconde couche
Fonctionne avec python 3.11
